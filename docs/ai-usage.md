# AI 工具使用记录

> 本文区分“辅助开发的 AI”和“运行时检测方法”，避免把开发工具能力写成检测效果。

| 环节 | 实际使用 | 验证方式 |
|---|---|---|
| 需求与方案 | OpenAI Codex 桌面 Agent 读取招聘要求，辅助收敛检测合同与项目边界 | 对照原始任务逐项检查交付项 |
| 实现 | Codex 辅助编写 Python CLI、Pydantic schema、确定性 mock、评估和报告代码 | 代码 diff 审查与 16 项自动化测试 |
| 文档 | Codex 辅助整理 README、SPEC、评估分析和文件索引 | 指标均从保存预测复算，截图来自真实本地报告 |
| 运行时检测 | 选定结果使用 `mock-rules-v2`，未调用生成式模型 | 标签不进入检测入口；规则不按样本 ID 分支 |
| 人工检查 | 人工核对 20 条 ID、混淆矩阵、`h16` 误报与 `h07` 首轮漏检 | 与 ground truth 按 ID 独立比较 |

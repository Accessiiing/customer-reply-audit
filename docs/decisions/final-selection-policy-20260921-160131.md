# 决策：最终版本选择规则

- 决策时间：2026-09-21 16:01:31 +08:00
- 状态：已确认

## 决定

只有三个版本都完成真实运行后才产生最终赢家，排序键冻结为：

1. `error_count == 0`，否则版本不具备获胜资格。
2. `decision_coverage` 降序。
3. `balanced_accuracy` 降序，作为主要质量指标。
4. `F1` 降序。
5. 正常回复误报率升序。
6. 运行耗时升序。

若质量指标完全相同，优先选择外部依赖更少的版本：`mock` → `hybrid` → `jev`。

## 为什么

20 条数据含 18 个正例、2 个负例，只看 Accuracy 或 F1 会奖励“全部报幻觉”。先检查故障和覆盖率，再以 Balanced Accuracy 为主，才能约束负例区分能力。

## 禁止

- 没有官方 Jev 真实运行时，不得用 stub/mock 结果选择最终版。
- 不得在看到三版结果后修改排序规则。

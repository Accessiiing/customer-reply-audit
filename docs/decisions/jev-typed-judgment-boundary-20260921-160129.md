# 决策：Jev 只负责类型化语义判断

- 决策时间：2026-09-21 16:01:29 +08:00
- 状态：已确认

## 决定

Jev 只判断封闭选项：证据关系、问题类型、实质性和知识条件覆盖。以下职责保留在确定性代码中：

- 原文分段与候选编号。
- 引文复制与存在校验。
- 严重度规则、概率门禁和最终聚合。
- ground truth 关联、指标计算和最终版本选择。

关系和证据编号合并为一个 Choice，避免让后一个 Jev 问题依赖前一个问题的答案。

## 为什么不让 Jev 生成 Claim JSON

Jev 返回 Choice、Noul、Score 等类型化决策，不生成任意文本。强行模拟 Chat Completions 会失去它的接口优势，也会重新引入伪造引文和格式修复问题。

## 边界

类型安全不等于语义正确。低概率、分布不集中、关系与证据不一致时必须进入 `needs_review`。

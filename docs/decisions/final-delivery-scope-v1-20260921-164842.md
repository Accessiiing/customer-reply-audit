## 决定

最终 `main` 只包含已经完成本地验证的 V1：确定性 `mock-rules-v2`、证据校验、独立评估、HTML 报告、测试和招聘方格式 README。

## 为什么

求职交付首先需要可复现、可解释、可审查。依赖临时促销额度、非官方中转或未完成全量验证的能力，会增加复现变量，却不能形成可信的效果对照。

## 验收

1. `uv sync --extra dev` 成功。
2. 16 项测试通过。
3. 仓库内脱敏样例能生成预测、评估和 HTML 报告。
4. README 的 run ID、指标、模式和截图一致。
5. Git 不包含密钥、招聘原始附件或本地运行目录。

# 决策：三版本并行实验

- 决策时间：2026-09-21 16:01:26 +08:00
- 状态：已确认
- 触发：需要把 Jev 前沿技术转化为可验证的招聘项目亮点。

## 决定

保留并统一评估三个版本：

| 版本 | 运行模式 | 职责 |
|---|---|---|
| V1 | `mock` | 现有确定性规则基线 |
| V2 | `jev` | Jev 类型化语义判断 |
| V3 | `hybrid` | 硬规则处理确定冲突，Jev 处理语义关系与遗漏 |

三版必须使用同一输入、同一 ground truth、同一评估代码。不得因为新技术较新就预设它获胜。

## 为什么不覆盖 V1

没有基线就无法证明 Jev 带来的是准确率、覆盖率、速度或成本收益，还是只增加了技术名词。保留 V1 换来可复现的因果对照。

## 验收

- 三版各自产生独立 run_id 和 predictions。
- comparison 同时报告质量、覆盖率、故障和运行开销。
- 最终版本由冻结排序规则选择。
